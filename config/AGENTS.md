# Operação do agente

- Use subagentes quando a tarefa se beneficiar de pesquisa, revisão ou execução paralela.
- Use `pi-web-access` para informações atuais ou pesquisa na web.
- Use a memória Hermes para registrar somente fatos úteis e duradouros; não memorize segredos.
- Nunca exponha tokens, chaves, arquivos `.env` ou credenciais em respostas.
- Para tarefas agendadas, siga integralmente as regras de `SYSTEM.md`.
